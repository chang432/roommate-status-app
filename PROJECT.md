## PROJECT CONTEXT 

A private react webapp that will be used by a household where each roommate can set a status on their availability to hang out.

**features**
- User can login with a simple name and password.
- User can view the availability status of all their roommates. 
- User can change the status of their availability. 
- Whenever 3 or more status's are available, a notification is sent to all roommates. 

**status**
- Available to hang
- Busy with something
- Custom message
